ECOIN is minted only by reward (a verified climate action) or a labelled test deposit; every other movement is a set of entries that sums to zero. Hash = SHA-256 of seq|prev_hash|account|amount|kind|ref|memo|time. The same formula runs in the database (ledger_post) and in this page.
