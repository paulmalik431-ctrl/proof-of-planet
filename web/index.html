Built to be questioned / 06

Trust is a system
property.

Consent first. People agree before evidence is checked.

Private by design. Public records use pseudonyms; phone numbers stay private and pickup points are rounded.

Fail safe. Unclear evidence is held for better proof. Disputes go to a person.

Open to inspection. Public views expose only what is safe to share; the ledger can be checked in a browser.

Meta Model API runs in Standard mode. Meta’s free developer credit terms permit use of submitted data to improve its products; the consent flow discloses this. ECOIN in this build is a test ledger.
