How it works

From a photo to a payment, on Meta

  1. Report on WhatsApp. “I planted a tree.” Text or photo, any language. WhatsApp Cloud API
  2. The agent collects the evidence. It asks for exactly what is missing — a photo, a before/after pair, your location. Muse Spark 1.3 · tool calling
  3. Meta AI looks. SAM 3.1 finds and counts saplings, litter, bottles and cans. Muse Spark answers fixed questions: same place? alive? edited? SAM 3.1 Muse Spark 1.3
  4. Rules decide, not the model. Verified, needs better evidence, or contradicted — with plain reasons. Unclear never becomes an accusation.
  5. ECOIN is paid on a public ledger. Each entry is hash-chained to the last. Anyone can re-check the whole chain in their browser.

The design rule

The AI can look and talk.
Only rules can pay.

The agent has no tool that moves money. Its only route to a payment is verify_claim, which runs SAM 3.1 and Muse Spark, applies fixed rules, and credits the protocol's reward — never an amount the model chooses.

Reused photos, places that don't match, trees that died, or images that look AI-made are caught by the same checks. We attack our own system with Muse Image fakes and publish the results.

What ECO pays for today

Tree planting

Photo + location. 100 ECOIN, then 400 more if it is alive 30 days later at the same spot.

Cleanup

Before and after photos. SAM 3.1 counts the litter removed: 50 + 10 per item, up to 300.

Recycling

Bottles and cans laid out. SAM 3.1 counts each one: 5 ECOIN per item, up to 200.

Next

New actions are protocols — data, not code. Merchants accept ECOIN; face pay with a WhatsApp code backup is on the roadmap.

Responsible by design

Trust, without exposing people

  • Consent first: nothing is checked until the person agrees that their photos and location form a public Evidence File.
  • Phone numbers are never published; people appear as pseudonyms like eco_3f9a….
  • Meta Model API in Standard mode only — contributor models that train on data are refused in code.
  • Ambiguous evidence is “needs better evidence”, and the agent says what photo would settle it.
  • Every check and every ledger entry is append-only in the database.
  • ECOIN here is a test ledger, not a cryptocurrency for sale.
