Exhibit 04 · The design rule

The AI can look and talk.
Only rules can move money.

The agent chooses which tool to use. Each tool enforces its own rules, and ECOIN can only move through four gates:

Mint: only after Witness checks find the evidence consistent. The amount comes from the protocol, never from the model.
Escrow: only when the buyer accepts the offer, and only from their own balance.
Release: only when the buyer confirms delivery, or a human reviewer decides a dispute.
Pay: only with the 6-digit code sent to the customer's WhatsApp (stored as a hash, valid for 5 minutes, 3 tries).

Every entry is hash-chained and append-only, and the database rejects overdrafts. Check the whole chain yourself →

Exhibit 05 · ECOIN

Earned only for verified climate action.

  • No proof, no token. New ECOIN is minted only by a verified action.
  • Spent on trades and everyday payments.
  • Escrow: each trade's ECOIN is held as collateral until delivery is confirmed.
  • Reserve: 30% of every fee builds an audited ECOIN Reserve, visible on the ledger.
  • Intelligence: the evidence behind every ECOIN gives funders a live view of climate activity in Atlas.

Exhibit 07 · Responsible by design

Trust without exposing people

  • Consent first. Nothing is checked until the person agrees that their photos and location become a public Evidence File.
  • Pseudonyms only. Phone numbers are never published; people appear as eco_3f9a…, and pickup points are rounded to about 1 km.
  • No accusations. If the evidence is unclear, the result is "needs better evidence", and the agent says which photo would settle it.
  • A person decides every dispute. The AI's recommendation and the human's decision are both shown on the trade page.
  • No face database and nothing biometric on the ledger. Face pay waits for a certified provider; the WhatsApp code works today.
  • Meta Model API runs in Standard mode; contributor models are refused in code. Disclosure: This hackathon build runs on Meta's free developer credits; under those terms Meta may use what is sent to its models to improve its products. The consent message says so too. ECOIN in this build is a test ledger.
